# Распознавание голоса: диагностика и исправление
> Дата создания: 2026-11-10

## Что обнаружено

Проверены оба инстанса VibeCodex. Telegram получает голосовые и передаёт
их на локальное распознавание. В журналах есть ошибки запуска с пустым stderr:
`Transcription failed: Command failed: .../bin/transcribe.sh ...`.
Содержимое пользовательских записей здесь не сохраняется.

Фактический `bin/transcribe.sh` оказался старым запускателем whisper.cpp:
он конвертирует аудио через отдельный ffmpeg, запускает `whisper-cli` и
скрывает stderr распознавателя через `2>/dev/null`. При этом рядом уже есть
рабочие `.voice-venv`, faster-whisper и модель small. Причина появления старого
запускателя вместо ожидаемого не установлена; по одной дате файла это выяснить
нельзя.

У старого обработчика одинаковый лимит вычисления **120 секунд** для любого
голосового. Длина сообщения не передавалась распознавателю. Сохранившийся
временный OGG/Opus имеет длительность **137,0465 секунды**. Наличие аудио
на диске и вызова декодера отличает этот случай от отсутствия файла в Telegram.

Короткий тест показывает, что whisper.cpp не сломан полностью: он распознал
11 секунд контрольной речи. Проверка длинной записи нужна отдельно; простое
переключение движка без изменения лимита не решает произвольную длину аудио.

## Изменение

- Обработчик использует версионируемый `scripts/transcribe.sh`; игнорируемый
  Git файл `bin/transcribe.sh` больше не определяет выбор движка.
- Python использует установленный **faster-whisper 1.2.1**, **PyAV 16.1.0**,
  CPU int8, три потока, beam size 3, VAD и автоматическое определение языка.
  Модель small загружается локально; API-ключ и выгрузка речи во внешний
  сервис не нужны. Для декодирования OGG/Opus используется PyAV.
- Бюджет вычисления: `min(1800, max(120, 60 + 6 × duration))` секунд.
  Для сообщения 137 секунд это **882 секунды**, а не 120. Верхняя граница
  ограничивает зависший процесс; это не обещание указанного времени ожидания.
- Shell делает `exec` Python: остановка по тайм-ауту попадает в декодер,
  а не только в промежуточную оболочку.
- Ошибка по времени содержит лимит и длительность записи. Ошибки кода выхода,
  отсутствия модели/аудио и пустой речи различаются. Распознанный пользовательский
  текст не пишется в обычный журнал.

Требуется перезапуск инстансов, чтобы новый Telegram-обработчик загрузился.
Распознаватель на Python читается заново при каждом голосовом. Инструкции
управления — в management; не следует запускать второй polling того же токена.

## Проверки

Контрольная запись: публичный `tests/jfk.flac` из
[репозитория Whisper](https://github.com/openai/whisper), 11 секунд.
SHA256: `63a4b1e4c1dc655ac70961ffbf518acd249df237e5a0152faae9a4a836949715`.
Она используется как проверка запуска и декодирования, а не как оценка
качества русской речи или устойчивости на произвольных голосовых.

| Проверка | Результат |
|---|---|
| Старый запускатель, 11 с FLAC | Успех, 42,11 с вычисления |
| Установленный faster-whisper, тот же FLAC | Успех, 31,78 с |
| Старый запускатель, 44 с OGG/Opus из повторов контрольной речи | Успех, 74,56 с; короткий Opus тоже работает |
| Тесты бюджета/аргументов/ошибок/тайм-аута | 8/8, 0 ошибок, 0 пропусков, 5,09 с |
| TypeScript `tsc --noEmit` | Успех |
| Сохранившаяся запись, 137,0465 с, старый запуск | Тайм-аут через 120,31 с; результат отвергнут |
| Та же запись, новый запускатель | Успех за 124,68 с, код выхода 0, 1684 символа текста |
| Изолированная копия только подготовленного коммита | TypeScript успешен; те же 8/8 тестов, 2,40 с |

Таким образом, тайм-аут **воспроизведён**. Даже новый движок на этой записи
завершается позже 120 секунд: замены движка без исправления лимита недостаточно.
Процесс старого теста и его дочерний декодер остановлены вместе, чтобы не
оставлять вычисление в фоне. Оригинальная временная запись не изменялась;
аудио и распознанный личный текст в Git не включаются.

Проверена локальная обработка сохранённого OGG/Opus, не новое входящее сообщение
через Telegram. Точность слов русской речи без эталонной расшифровки не измерялась.
Распознавание без ошибки не означает нулевую ошибку текста.

Статус: исправление и проверки завершены. Текущий инстанс `projects` должен
перезапуститься отложенно после ответа; запуск через management
`bin/bots.sh defer projects` ждёт окончания активного хода. До фактического
перезапуска новый обработчик не считается загруженным. Для второго инстанса
используется тот же исходный код и требуется такой же перезапуск.

## Воспроизведение

Установка локального окружения и загрузка модели уже выполнены на сервере;
они исключены из Git. Если окружение восстанавливается независимо:

```bash
uv venv .voice-venv
uv pip install --python .voice-venv/bin/python faster-whisper==1.2.1 av==16.1.0
```

Модель `Systran/faster-whisper-small` помещается в `models/faster-whisper-small`
с `model.bin`, `config.json`, `tokenizer.json`, `vocabulary.txt`.
Затем из корня репозитория:

```bash
scripts/transcribe.sh /путь/к/контрольному-аудио.oga
node_modules/.bin/tsx --test test/transcription.ts
node_modules/.bin/tsc --noEmit
```

Описание декодирования без отдельного системного ffmpeg:
[официальная документация faster-whisper](https://github.com/SYSTRAN/faster-whisper#requirements).
